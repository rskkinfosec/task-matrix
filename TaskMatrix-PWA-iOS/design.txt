# TaskMatrix PWA - Module Design Document

## System Architecture Overview

```
┌─────────────────────────────────────────────────────────────────────┐
│                    TASKMATRIX PWA APPLICATION                        │
└─────────────────────────────────────────────────────────────────────┘

┌──────────────────┬──────────────────┬──────────────────┬─────────────┐
│   Presentation   │     State        │     Sync         │  Storage    │
│     Layer        │    Management    │     Engine       │   Layer     │
└──────────────────┴──────────────────┴──────────────────┴─────────────┘

    UI Components      Data Models      Sync Logic       localStorage
     (HTML/CSS)       (Tasks/Tabs)      (Drive API)      Firebase Auth
    (JavaScript)     (State Arrays)     (XLSX)           Google Drive
```

### 3. SYNC ENGINE

```
┌─────────────────────────────────────────────────────────────────┐
│                   Sync State Machine                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│    Local Changes (Task Operations)                              │
│           │                                                      │
│           ▼                                                      │
│    ┌──────────────┐                                             │
│    │ Added        │ ◄──────────────┐                            │
│    │ Updated      │                │                            │
│    │ Deleted      │        ┌───────┴────────┐                   │
│    └──────────────┘        │                │                   │
│           │         syncToDrive()    syncFromDrive()            │
│           │         (Upload)         (Download)                 │
│           ▼                │                │                   │
│    ┌──────────────┐        │                │                   │
│    │ SYNCED       │ ◄──────┘                │                   │
│    └──────────────┘                        ▼                   │
│           ▲              ┌──────────────────────┐               │
│           │              │ Remote Changes       │               │
│           │              │ (Drive Sheet Rows)   │               │
│           └──────────────┤                      │               │
│                          │ GUID/Hash Matching  │               │
│                          │ Timestamp Conflict  │               │
│                          │ Resolution          │               │
│                          └──────────────────────┘               │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘

Sync Workflow:

    ┌─────────────┐
    │   Device A  │
    └─────────────┘
         │ saveTasks() every 3s
         ▼
    ┌──────────────────┐
    │ syncToDrive()    │
    │ - Export to XLSX │
    │ - Mark SYNCED    │
    └──────────────────┘
         │
         ▼ Google Drive API
    ┌────────────────┐
    │ taskmatrix-    │
    │ backup.xlsx    │
    └────────────────┘
         │
         ▼ Google Drive API
    ┌──────────────────┐
    │ syncFromDrive()  │
    │ - Import XLSX    │
    │ - Merge state    │
    │ - Resolve        │
    │   conflicts      │
    └──────────────────┘
         │
         ▼
    ┌─────────────┐
    │   Device B  │
    └─────────────┘

Key Functions:
- syncToDrive()         : Upload tasks to Drive
- syncFromDrive()       : Download and merge tasks
- mergeRemoteState()    : Combine local + remote
- generateUUID()        : Stable task ID
- generateTaskHash()    : Content hash for dedup
```

Data Flow:
    In-Memory       →  localStorage  →  Google Drive
    (tasks[] array)     (JSON string)   (XLSX file)

    (XLSX file)        (JSON parse)     (tasks[] array)

## Data Structures Diagram

```
TASK OBJECT (Full State):
┌────────────────────────────────────────────────────────┐
│ id                    : number (local ID)               │
│ guid                  : string (cross-device ID)        │
│ title                 : string                          │
│ description           : string                          │
│ parentTab             : string (tab name)               │
│ quadrant              : 'q1'|'q2'|'q3'|'q4'            │
│ priority              : 'low'|'normal'|'high'|'urgent' │
│ estimateValue         : number (hours/days/weeks)      │
│ estimateUnit          : string                          │
│ deadline              : string (YYYY-MM-DD)            │
│ recurring             : boolean                        │
│ frequency             : 'daily'|'weekly'|'monthly'    │
│ completed             : boolean                        │
│ completedAt           : string (ISO timestamp)         │
│ deadlineMissed        : boolean                        │
│ createdAt             : string (ISO timestamp)         │
│ updatedAt             : string (ISO timestamp) ◄─┐     │
│ syncState             : 'Added'|'Updated'|'SYNCED'... │ Sync
│ fieldUpdatedAt        : object {field: timestamp}  ◄─┤ Control
│ canonicalHash         : string (content hash) ◄────┘   │
│ mustHave              : boolean                        │
│ goodToHave            : boolean                        │
└────────────────────────────────────────────────────────┘

SYNC STATE TRANSITIONS:
        Creation       Edit           Delete
        (user)         (user)         (user)
           │             │              │
           ▼             ▼              ▼
        'Added' ───→ 'Updated'      'Deleted'
           │             │              │
           └─────────────┴──────────────┘
                      │
                      ▼ syncToDrive()
                   'SYNCED' ◄──────┐
                      │            │
                      └────────────┘
                  (stays SYNCED until
                   next edit/delete)
```

## API Endpoints Used

```
GOOGLE DRIVE API:

1. List Files:
   GET /drive/v3/files?q=name='taskmatrix-backup.xlsx'

2. Download File:
   GET /drive/v3/files/{fileId}?alt=media

3. Upload File:
   POST /upload/drive/v3/files/{fileId}?uploadType=media

4. Create File:
   POST /drive/v3/files

FIREBASE AUTH:

1. Sign In with Redirect:
   auth.signInWithRedirect(googleProvider)

2. Get Redirect Result:
   auth.getRedirectResult()

3. Sign Out:
   auth.signOut()

4. Current User:
   auth.currentUser.getIdToken()
```

## Performance Characteristics

```
Operation               Time Complexity    Space Complexity
─────────────────────────────────────────────────────────
Add Task                O(1)               O(1)
Update Task             O(n) search        O(1) update
Delete Task             O(n) search        O(1) mark
Search Tasks            O(n)               O(m) results
Sync to Drive           O(n × 17 fields)   O(n) temp array
Import from Drive       O(n)               O(n × 17 fields)
Merge States            O(n × m) GUID match O(n+m) union
Deduplication           O(n × log n) hash  O(n) hash table

Where n = number of tasks, m = number of remote tasks

Expected Performance:
- 1000 tasks:     Sync ~100ms, Import ~150ms
- 5000 tasks:     Sync ~500ms, Import ~750ms
- 10000 tasks:    Sync ~1000ms, Import ~1500ms
```

## Deduplication Strategy

```
LAYER 1: Initialization
┌─────────────────────────────────┐
│ Load from localStorage          │
│ Filter out default tab IDs      │
│ Remove duplicate tab names      │
└─────────────────────────────────┘
           │
           ▼
LAYER 2: During Sync Download
┌─────────────────────────────────┐
│ Parse XLSX sheet names          │
│ Map display names to default IDs │
│ Only create if not exists       │
└─────────────────────────────────┘
           │
           ▼
LAYER 3: After Merge
┌─────────────────────────────────┐
│ Remove default tab IDs from     │
│ customTabs array                │
│ Deduplicate by name (case-insensitive)
└─────────────────────────────────┘
           │
           ▼
LAYER 4: UI Rendering
┌─────────────────────────────────┐
│ Deduplicate before rendering    │
│ No delete buttons on defaults   │
└─────────────────────────────────┘
```
